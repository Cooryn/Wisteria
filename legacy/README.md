# Legacy App Snapshot

This directory keeps the original Wisteria Tauri desktop application as reference material during the plugin rebuild.

Moved here:

- `src/`
- `src-tauri/`
- `public/`
- former root app config files such as Vite, Tauri, and the old package metadata
- the original project readme as `README.old.md`

The active build no longer depends on any code in `legacy/`.
